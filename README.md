# Tempo — смысловая графика поверх видео

Новый независимый проект. Один готовый ролик → локальное распознавание речи с таймкодами → OpenAI выбирает смысловые акценты → просмотр и правка плана → анимированные вставки → MP4.

Обычных субтитров, склейки, баннера подписки и переозвучки нет. Три варианта оформления: акцентное слово, цифра с пояснением, краткий тезис. Единая палитра, кириллица, плавная анимация, ограничение частоты вставок. Для теста достаточно загрузить файл в локальном веб-интерфейсе.

## Запуск

Нужны Python 3.11+, FFmpeg и FFprobe в PATH, шрифт DejaVu Sans (кириллица). На Ubuntu: `sudo apt-get install ffmpeg fonts-dejavu-core`.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell вместо предыдущей строки:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py --server.address 127.0.0.1
```

Откройте адрес, напечатанный Streamlit, загрузите видео, введите OpenAI API key и идентификатор доступной вам модели. Ключ хранится только в памяти сессии. Можно также задать `OPENAI_API_KEY`, `OPENAI_MODEL`. Подписка ChatGPT не заменяет оплату API.

Отдельный флажок разрешает отправку расшифровки в OpenAI. Само видео в OpenAI не загружается. Распознавание faster-whisper выполняется локально; первый запуск скачивает модель. Перед рендером проверьте распознанные цифры, отрицания и выбранные фразы в плане.

Для проверки графики без API: загрузите видео длиной не меньше 8 секунд и `example-plan.json`, примените план, нажмите «Собрать видео». Тексты примера демонстрационные.

## Командная строка

```bash
python engine.py input.mp4 result.mp4 --plan example-plan.json
# Автоматический план, с OPENAI_API_KEY и OPENAI_MODEL в окружении:
python engine.py input.mp4 result.mp4
```

План — JSON-массив полей `start`, `end` (секунды), `kind` (`keyword`, `stat`, `statement`), `text`, `label`. Рядом с результатом CLI сохраняется редактируемый `.plan.json`.

## Практические ограничения

- Это первая версия с фиксированной системой оформления, а не неограниченный генератор дизайнерской графики. Качество оценивайте на ваших роликах.
- Автоматический выбор использует речь, не анализирует лица и композицию. Положение карточек фиксировано в нижней части кадра: перед публикацией проверьте перекрытия.
- Видео перекодируется в H.264, CRF 17, 30 fps с исходным соотношением сторон; нечётные размеры уменьшаются на 1 px. HDR/альфа не поддерживаются. Rotation metadata отклоняется с понятной ошибкой.
- Первая аудиодорожка копируется без перекодирования, нормализации и добавления звуков. Кодек исходного аудио должен поддерживаться MP4; иначе сборка завершится ошибкой. Остальные аудиодорожки и субтитры не переносятся.
- На длинных видео CPU-рендер и распознавание могут быть медленными. Начните с 10–30 секунд. Интерфейс предназначен для локального теста, не для публичного сервера.
- GitHub хранит исходный код; это не развёрнутый сайт. Автопостинг и n8n не подключены.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Интеграционный тест создаёт синтетическое видео с аудио, накладывает кириллическую карточку и проверяет неизменность пакетов аудиодорожки. Сетевой API и скачивание Whisper-моделей в тестах не запускаются.
